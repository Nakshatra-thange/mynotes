# 📝 How to use this site

## Add a note from code
1. Create a file in `notes/`, e.g. `notes/my-idea.md`
2. Put a date at the top (optional `pinned: true` keeps it first)
3. Run `node build.js` and refresh

## Add a note from the browser
- Click the ✎ button (or press **N**)
- Just start typing. The first line becomes the title.
- **Paste or drag in photos** — they appear right in the note
- Use the checklist and table buttons in the toolbar

## Shortcuts
| Key | Action |
|---|---|
| N | New note |
| / | Search |
| Cmd/Ctrl + B | Bold |
| Cmd/Ctrl + I | Italic |
| Tab | Next table cell |

Notes you write in the browser are saved on this device. Notes in `notes/` are part of your site.
